# A2 PermissionRequest 审批（AskUserQuestion 飞书选项）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 去掉 `--dangerously-skip-permissions`（hook 可触发），ApprovalGate 让 AskUserQuestion 走飞书结构化选项（文本回复），其他工具全 allow（等价 bypass）。

**Architecture:** hub 转发——hook POST hub `/api/hook/approval` → ApprovalGate classify → AskUserQuestion 经 WS `approval-request` 转发 Code咪 → 飞书选项卡片 → 用户回复 → WS `approval-response` → answers 注入。其他工具 hub 立即 allow。

**Tech Stack:** TypeScript (ESM), @larksuiteoapi/node-sdk, ws, vitest

## Global Constraints

- 不用 `--dangerously-skip-permissions`（default 模式，hook 可触发）
- ApprovalGate：只 AskUserQuestion 转发飞书，其他全 allow（等效 bypass）
- 飞书文本回复（"1"或选项名，非按钮）
- hub↔Code咪 WS 新消息：`approval-request`/`approval-response`
- commit message 中文；不主动 push
- 5min 审批超时 → deny（fail-closed）

```typescript
/**

 * 行为等价 --dangerously-skip-permissions，但保留 AskUserQuestion 的 PermissionRequest hook。

export function classify(toolName: string, _input: Record<string, unknown>): 'allow' | 'question' {
  if (toolName === 'AskUserQuestion') return 'question';
```

```typescript
this.app.post('/api/hook/approval', async (req, res) => {
  const toolName = req.body?.tool_name as string;
  const toolInput = req.body?.tool_input || {};
  const toolUseId = req.body?.tool_use_id as string;
  const botName = (req.query.bot as string) || '';
  const verdict = classify(toolName, toolInput);

  if (verdict === 'allow') {
    // 等效 bypass：非 AskUserQuestion 立即 allow
    res.json({ hookSpecificOutput: { hookEventName: 'PermissionRequest', decision: { behavior: 'allow' } } });
    return;

  // AskUserQuestion → WS 转发给对应 bot（Code咪）
  const botWs = this.botConnections.get(botName);
  if (!botWs) {
    // bot 未连接，fail-closed deny
    res.json({ hookSpecificOutput: { hookEventName: 'PermissionRequest', decision: { behavior: 'deny', message: `bot ${botName} 未连接` } } });

  res.json({ hookSpecificOutput: { hookEventName: 'PermissionRequest', decision: reply } });
```

```typescript
/** 收到 AskUserQuestion 选项请求 → 发飞书选项卡片 → 等用户回复 → WS 回 approval-response */
private handleAskUserQuestion(toolUseId: string, questions: any[]): void {
  const targetChatId = this.responseChatId || this.defaultChatId;
  if (!targetChatId) return;

  // 渲染选项卡片（"问题 + 1.xxx 2.xxx + 回复编号/选项名"）
  const lines: string[] = ['🟡 请选择（回复编号或选项名）：'];
  for (const q of questions || []) {
    if (q.question) lines.push(String(q.question));
    (q.options || []).forEach((o: any, i: number) => {
      lines.push(`${i + 1}. ${o.label}${o.description ? ' - ' + o.description : ''}`);
    });
  }
  this.patchCard('yellow', '🟡 请选择', lines.join('\n'));

  // 等用户飞书回复
  const promise = new Promise<Record<string,string>>((resolve) => {
    this.pendingQuestions.set(toolUseId, resolve);
    setTimeout(() => {  // 5min 超时
      if (this.pendingQuestions.has(toolUseId)) {
        this.pendingQuestions.delete(toolUseId);
        resolve({});
      }
    }, 5 * 60 * 1000);
  });

  promise.then((answers) => {
    // WS 回 approval-response
    this.remoteWs?.send(JSON.stringify({
      type: 'approval-response', toolUseId,
      decision: { behavior: 'allow', updatedInput: { questions, answers } },
      botName: this.config.botName,
    }));
    this.patchCard('green', '🟢 已选择', JSON.stringify(answers));
  });
}
```
